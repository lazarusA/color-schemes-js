# Catalogue of ColorSchemes

The library includes hundreds of curated colorschemes across multiple scientific, artistic, and visualization domain categories.

You can search and filter scheme names programmatically using `findColorScheme()`:

```typescript
import { findColorScheme } from 'color-schemes';

findColorScheme("ocean");
```

## Category Overview

### cmocean
Beautiful colormaps for oceanography. Designed by Kristen Thyng.  
*Reference: [cmocean matplotlib](https://matplotlib.org/cmocean/)*

::scheme-list-showcase{category="cmocean"}
::

### scientific
Perceptually uniform scientific colormaps designed by Fabio Crameri to prevent visual distortion of data.  
*Reference: [Scientific Colour Maps](http://www.fabiocrameri.ch/colourmaps.php)*

::scheme-list-showcase{category="scientific"}
::

### matplotlib
Popular colormaps from Python's Matplotlib library, including `viridis`, `inferno`, `plasma`, `magma`, and `cividis`.  
*Reference: [Matplotlib Colormaps](https://matplotlib.org)*

::scheme-list-showcase{category="matplotlib"}
::

### colorbrewer
Classic palettes designed by Cynthia Brewer for cartography and visualization.  
*Reference: [ColorBrewer 2.0](http://colorbrewer2.org/)*

::scheme-list-showcase{category="colorbrewer"}
::

### gnuplot
Classic palettes used in Gnuplot graph plotting software.  
*Reference: [GNUPlot](http://www.gnuplot.info)*

::scheme-list-showcase{category="gnuplot"}
::

### colorcet
Perceptually uniform colormaps designed by Peter Kovesi.  
*Reference: [ColorCET](https://colorcet.holoviz.org)*

::scheme-list-showcase{category="colorcet"}
::

### CMasher
Scientific colormaps designed for accessible, informative data presentation by Ellert van der Velden.  
*Reference: [CMasher Docs](https://cmasher.readthedocs.io/)*

::scheme-list-showcase{category="cmasher"}
::

### cmyt
Scientific colormaps from the yt project for astrophysical simulations.  
*Reference: [cmyt Repository](https://github.com/yt-project/cmyt/)*

::scheme-list-showcase{category="cmyt"}
::

### Seaborn
Color palettes used by Seaborn, Python's statistical data visualization library.  
*Reference: [Seaborn Palettes](http://seaborn.pydata.org/tutorial/color_palettes.html)*

::scheme-list-showcase{category="seaborn"}
::

### ggthemes / Tableau
Color palettes inspired by Tableau and `ggplot2` themes.  
*Reference: [ggthemes](https://github.com/jrnold/ggthemes)*

::scheme-list-showcase{category="tableau"}
::

### Color-Vision Deficient (CVD) Friendly
Palettes specifically designed or tested for accessibility by viewers with color-vision deficiencies (protanopia, deuteranopia, tritanopia), by authors such as Paul Tol, Masataka Okabe, and Kei Ito.

::scheme-list-showcase{category="cvd"}
::

### Artistic & Masterworks
Artistic palettes inspired by fine art, cinema, and historical color studies (MetBrewer, Ghibli, Wes Anderson, Sanzo Wada, Leonardo da Vinci, Vermeer).

::scheme-list-showcase{category="artistic"}
::

### UI & Syntax Themes
Themes inspired by popular developer environments and syntax highlighters, including Catppuccin, Nord, and Dracula.

::scheme-list-showcase{category="themes"}
::

### Flags & National Palettes
Official color palettes derived from national flags around the world.
