# References & Credits

## ✦ cmocean
Beautiful colormaps for oceanography by Kristen Thyng: [cmocean](https://matplotlib.org/cmocean/)

## ✦ scientific
Perceptually uniform colormaps by Fabio Crameri: [Scientific Colour Maps](http://www.fabiocrameri.ch/colourmaps.php)

## ✦ matplotlib
Matplotlib Python visualization library colormaps: [Matplotlib](https://matplotlib.org)

## ✦ colorbrewer
Cartographic color advice by Cynthia Brewer: [ColorBrewer](http://colorbrewer2.org/)

## ✦ gnuplot
Colormaps from [GNUPlot](http://www.gnuplot.info)

## ✦ colorcet
Perceptually accurate colormaps collection by Peter Kovesi: [ColorCET](https://colorcet.holoviz.org)

## ✦ Seaborn
Color palettes from Seaborn statistical visualization library: [Seaborn Palettes](http://seaborn.pydata.org/tutorial/color_palettes.html)

## ✦ ggthemes / Tableau
Palettes inspired by ggplot2 themes and Tableau: [ggthemes](https://github.com/jrnold/ggthemes)

## ✦ Color-Vision Deficient (CVD) Friendly Schemes
Schemes designed for accessibility by researchers such as Paul Tol, Masataka Okabe, Kei Ito, and Martin Krzywinski.

## ✦ Country Flags
Palette colors extracted from country and regional flags sourced via [Flagpedia](https://flagpedia.net), named using ISO 3166 two-letter country codes.

## ✦ General & Miscellaneous
Artistic, masterwork, and custom-themed palettes contributed by the open-source community.
