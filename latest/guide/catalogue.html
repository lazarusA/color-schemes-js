Catalogue of ColorSchemes

The library includes hundreds of curated colorschemes across multiple scientific, artistic, and visualization domain categories.

You can search and filter scheme names programmatically using findColorScheme():

import { findColorScheme } from 'color-schemes-js';

findColorScheme("ocean");
